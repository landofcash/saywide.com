# Evidence review

This is guidance for a candidate self-check, not certification or an independent
reviewer. Loading these instructions does not mean that a review has completed.

1. For every candidate assignment, read the referenced answer in context. Does
   it directly support the finding? Remove unsupported or ambiguous assignments;
   never infer agreement from an unanswered question.
2. Check all responses for counterevidence and overlooked minority concerns.
   Narrow overstated titles and summaries. Do not manufacture disagreement.
3. Check that each quote supports the claim and matches the source exactly.
   Use only existing answer identifiers. Never fabricate or repair an identifier.
4. Remove identifying details by selecting a different exact excerpt or omitting
   the quote. Do not paraphrase text while presenting it as an exact quotation.
5. Ensure suggested actions are proportionate and label uncertainty in limitations.
   Do not present respondent opinion as verified fact or a causal explanation.
6. Drop findings without adequate safe supporting evidence. If no defensible
   finding remains, do not invent one to satisfy the output schema.

Return the candidate using the supplied schema. Do not add counts, percentages,
confidence scores, or claims that backend validation has already succeeded.
